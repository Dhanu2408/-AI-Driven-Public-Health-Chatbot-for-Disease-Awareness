# AI-DRIVEN PUBLIC HEALTH CHATBOT FOR DISEASE AWARENESS

## 1. Project Overview

The **AI-Driven Public Health Chatbot for Disease Awareness** is an intelligent web-based application designed to educate people about common diseases and promote public health awareness. The chatbot uses Artificial Intelligence (AI) and Natural Language Processing (NLP) to understand user queries and provide accurate, instant, and easy-to-understand responses. Users can ask questions about diseases, symptoms, causes, preventive measures, and basic treatment information. The system aims to reduce misinformation by providing reliable health education while encouraging users to seek professional medical advice when required. Built using Python, Flask, HTML, CSS, JavaScript, and SQLite, the application offers a secure, responsive, and user-friendly platform that can be accessed anytime through the internet.

---

## 2. Problem Statement

People often search for medical information on the internet, but many websites provide inaccurate, outdated, or misleading information. This creates confusion and may lead to poor health decisions. Additionally, hospitals and healthcare professionals may not always be available to answer basic health-related questions immediately. There is a need for an intelligent system that provides trustworthy disease awareness information in a simple and interactive manner. This project addresses that challenge by developing an AI-powered chatbot capable of providing instant educational guidance about common diseases while promoting preventive healthcare practices.

## 11. Database Design

The project uses **SQLite** as the backend database.

### Users Table

Stores user registration details such as User ID, Name, Email, Password, and Registration Date.

### Disease Table

Stores disease name, symptoms, causes, prevention methods, treatment guidance, and additional health information.

### Chat History Table

Stores User ID, User Question, Chatbot Response, Date, and Time.

### Feedback Table

Stores User ID, Rating, Comments, and Submission Date.

The database is normalized to reduce redundancy and improve performance.
