# AI-DRIVEN PUBLIC HEALTH CHATBOT FOR DISEASE AWARENESS

## 1. Introduction

The **AI-Driven Public Health Chatbot for Disease Awareness** is an intelligent web-based application developed to provide reliable health-related information to users through an interactive chatbot. The system uses Artificial Intelligence (AI) and Natural Language Processing (NLP) to understand user questions and provide meaningful responses about various diseases. The chatbot is designed to educate people about common health conditions, their symptoms, causes, preventive measures, and basic treatment guidance. It helps users gain awareness about diseases and encourages them to seek professional medical advice whenever necessary. The application is available online, making health information accessible anytime and anywhere.

---

## 2. Problem Statement

Many people do not have immediate access to reliable health information. They often depend on social media or unverified websites, which may spread misinformation. Visiting hospitals for minor health-related queries can also consume time and resources. There is a need for an intelligent system that provides instant, accurate, and easy-to-understand health awareness information. This project addresses this problem by developing an AI-powered chatbot that provides trustworthy educational content related to public health.

## 4. Scope of the Project

The scope of this project includes providing educational information about common diseases through an AI chatbot. Users can ask health-related questions and receive instant responses. The chatbot can explain symptoms, causes, prevention methods, and basic first-aid guidance for common illnesses. The application also allows users to register, log in, view previous conversations, and submit feedback. In future, the system can be enhanced by integrating real-time medical databases, multilingual support, voice interaction, hospital appointment booking, and AI-based symptom prediction.

## 6. System Modules

### Module 1: User Authentication

This module allows users to register and securely log into the application. It includes account registration, login, password reset, and logout functionality. Authentication ensures that each user's information and chat history remain secure.

### Module 2: AI Chatbot

The chatbot is the core module of the system. Users can type health-related questions in natural language. The chatbot processes the input using AI and NLP techniques and provides meaningful responses based on the stored knowledge base.

### Module 3: Disease Awareness Database

This module stores information related to different diseases. It contains details such as disease name, symptoms, causes, prevention methods, and basic treatment guidance. The chatbot retrieves information from this database while responding to user queries.

### Module 4: Chat History

Every conversation between the user and the chatbot is stored in the database. Users can view their previous conversations whenever required.

### Module 5: Feedback System

After interacting with the chatbot, users can provide ratings and feedback. This helps improve the chatbot's performance and user experience.

## 7. Working Process

1. The user opens the chatbot website.
2. The user registers or logs into the application.
3. The chatbot interface appears on the screen.
4. The user enters a health-related question.
5. The chatbot processes the question using AI and NLP.
6. The system searches the disease knowledge database.
7. The chatbot generates an appropriate response.
8. The response is displayed to the user.
9. The conversation is stored in the chat history.
10. The user may provide feedback before logging out.
